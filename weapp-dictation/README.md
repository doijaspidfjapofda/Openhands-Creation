# 词间 · 教材词汇听写与错词复习（微信小程序交互原型）

面向中学生与家长的词汇听写小程序原型，覆盖「教材选词 → 手动/自动听写 → 家长批改 → 错词库 → 学生自主复习」闭环。

工程为原生微信小程序（WXML / WXSS / JavaScript），无 npm 依赖，数据保存在本机 Storage，**不连接真实教材库、账号系统或生产后端**。

## 一、导入与运行

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择本文件夹 `weapp-dictation`。
3. AppID 选择「测试号」即可；工程内已填写 `touristappid`，也可替换为自己的 AppID。
4. 基础库建议 3.5.5 及以上（最低 2.20.1，语音与窗口信息接口需要）。
5. 编译后从首页「教材听写」开始体验。

> 入口页是 `pages/setup/setup`。如果上次退出时停留在学生视图，入口会自动跳转到学生「今日复习」。

## 二、原型范围

已实现：

- 家长：教材选词、手动听写、自动听写、逐词批改、回改、题号跳转、结果统计、错词库、听写记录、未完成草稿恢复。
- 学生：今日复习、我的错词、看释义写拼写（首字母提示）、练习结果、练习记录。
- 家庭档案：默认 1 个，最多 3 个，错词 / 听写 / 练习按档案隔离。
- 空状态、无选择禁用、未批改提醒、播放占位提示。

本轮未实现（正式版需要）：

- 真实教材词表、音标 / 释义 / 例句校对、真实音频资产。
- 微信登录、家庭账号、云端数据库、跨设备同步、数据删除与隐私流程。
- 艾宾浩斯间隔复习排程。本轮 PRD 只要求「今日复习/首页提示待复习错词及入口」，当前首页展示全部当前错词；排程规则属于待确认项。
- 真机音质、音频时序、iPad 分屏与审核要求验证（本环境无法运行微信开发者工具）。

## 三、角色与演示数据

- 右上角分段控件切换「家长 / 学生」。
- 默认学生档案「小禾」。
- 演示词表：人教版七年级上/下册、八年级上册与北师大版七年级上册，共 32 个词。
- 演示记录：3 个当前错词、1 条历史听写、1 条自主练习。
- 右上角 `⋯` → 「重置演示数据」可恢复初始状态。

## 五、核心流程

### 手动听写

1. 选词页默认按当前档案的教材与 Unit 预选词表，可跨 Unit 增减。
2. 进入听写页后，单词、音标、中文释义默认显示；点「家长查看答案 / 收起答案」可整体隐藏或恢复。
3. 点大喇叭按钮按所选语言播报，可重复播放。
4. 点「写对了」或「需要练习」后立即保存并进入下一词；「上一个」可返回，已标记项有颜色提示，重新选择以最后一次为准。
5. 最后一个词批改后弹窗确认；也可以先跳到任意题号统一批改。
6. 未批改词不会算对；点「完成批改并保存」时若仍有未批改词，会提示数量，可选择继续或只保存已批改项。

### 自动听写

1. 进入播放页时单词、音标、释义默认隐藏；家长可通过「家长查看当前词」临时查看。
2. 设置 2–15 秒间隔，点「开始自动听写」按所选顺序逐词播报；间隔从当前语音结束后开始计时。
3. 支持暂停 / 继续（继续会重播当前词）、跳过、提前结束。
4. 播放结束后显示「开始批改」，进入与手动模式相同的逐词批改流程。

### 错词规则

- 写错：进入当前档案错词库；同一词不重复建条目，只累加次数。
- 家长听写写对：从当前错词库移出，但历史听写记录保留。
- 学生自主练习：只累加练习次数，不移出错词库。
- 移出后再次写错：重新进入错词库。

### 草稿与部分完成

- 每次标记都会写入草稿，返回选词页可继续或放弃。
- 放弃草稿不改变历史与错词库。
- 提前结束只保存已批改项，未批改项不影响统计与错词库。

## 七、数据与持久化

- Storage key：`wordnest-mini-v1`。
- 结构：`{ version, role, activeChildId, children[] }`。
- 每个学生档案包含：`wrong`（当前错词）、`history`（听写记录）、`practice`（自主练习）、`draft`（未完成草稿）、教材选择。
- 所有读取都经过 `utils/state.js`；数据层 `utils/store.js` 不依赖 `wx`，可在 Node 中测试。
- 本地存储只用于演示。正式版需要后端 / 云开发、账号权限、跨设备同步、数据导出与删除。

## 八、语音现状与接入

当前实现位于 `utils/audio.js`：

```js
audio.playWord(word, 'zh' | 'en', {
  onStart(mode, durationMs) {},
  onEnd() {}
});
```

- 优先读取词条的 `audio` 字段，用 `wx.createInnerAudioContext()` 播放；没有音频或播放失败时进入**演示占位**：按文本长度模拟播报时长，界面明确显示「演示占位 · 无真实语音」。
- 没有使用浏览器 `window.speechSynthesis`。
- 推荐正式接入方式：
  1. 预生成音频：TTS 离线生成中 / 英文 mp3，上传云存储，在词表写入 `audioZh` / `audioEn`（fileID 或 https 地址）。稳定、可缓存、易审核。
  2. 云函数实时合成：灵活但受延迟、并发与成本限制。
  3. 微信同声传译插件：需申请与审核，注意隐私与合规。
- 替换点：词表字段 + `audio.playWord` 内部实现，页面无需改动。

## 十、自检与测试

本环境无法运行微信开发者工具，因此提供三层脚本自检：

```bash
node scripts/check.js            # 工程结构、JSON/JS 语法、WXML 标签与表达式、事件绑定、样式括号
node tests/store.test.js         # 数据规则：草稿、判分、错词迁移、档案隔离
node tests/flows.test.js         # 页面流程：选词 → 自动听写 → 批改 → 结果 → 错词库 → 学生练习
node tests/components.test.js    # 组件行为：角色切换、档案新增/重置、底栏、弹窗、空状态
```

这些脚本能发现结构、语法与流程错误，但不能替代真机验证。导入开发者工具后，建议重点检查：

- iPhone 竖屏的顶部栏、底部导航安全区。
- iPad 宽屏双栏布局是否过度拉伸。
- 自动播报的间隔时序与后台切换后的恢复。
- 无音频时的占位提示是否清楚。

## 十一、后续接入云开发（建议）

1. 集合：`families`、`children`、`wordbooks`、`words`、`wrong_words`、`sessions`、`practices`、`drafts`。
2. 云函数：`login`（openid → family）、`getWordbook`、`saveDraft`、`finishSession`、`recordPractice`、`listWrongWords`。
3. 安全规则：所有读写限定 `familyId`；学生端只读自己的档案与错词。
4. 同步策略：本地先写、失败重试；草稿与最终结果需要幂等键（`draftId` / `sessionId`）。
5. 迁移：把 `utils/state.js` 的本地读写替换为云函数调用，保留 `utils/store.js` 的纯数据规则与测试。

## 十二、适配说明

- 内容区最大宽度 960px，宽屏 ≥ 900px 时选词 / 听写 / 错词库使用双栏。
- 页面底部预留 120px，避免被固定底栏遮挡；底栏使用 `env(safe-area-inset-bottom)`。
- 关键操作按钮最小高度 42–44px，适配触屏。
- `app.json` 开启 `resizable` 与 `pageOrientation: auto`，便于 iPad 体验。
