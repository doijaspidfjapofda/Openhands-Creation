Design System

暖纸底 + 一枚 PDF 红

面向长时间处理文档的桌面工具，视觉上要年轻、精致、不冷冰，但必须一眼被认成 PDF 工具。做法是：底色取纸张的暖白，强调色只用一个 PDF 语义红，其余分区用低饱和色块轻轻区分。所有数值都按 4px 基准与 WCAG AA 落地。

底色即产品语言。奶油白 #FBF6F1 让大面积白纸状卡片有边界，长时间看不会发灰。
红色只代表 PDF 与主操作。不做装饰性用红，避免误读成错误。
状态不靠颜色。每个状态都带图标与文字，色盲与灰度打印下同样可读。

05状态覆盖

每个工具至少覆盖 10 种状态。原型右上角的「演示状态」可以在任意面板之间切换，用来核对文案与层级。

状态触发表现可用操作
未选文件进入工具但未打开 PDF蓝色提示块 + 文件名占位选择 PDF / 用演示文档
加载中读取文件、生成缩略图骨架屏 + 38% 进度条等待（大文件提示）
可编辑文件就绪状态区清空，主按钮可用全部参数
处理中点击主按钮斜纹进度条 + 阶段文案 + 取消取消
完成流程结束琥珀色“演示完成”，明确未写文件再试一次（打开结果禁用并说明）
失败目录不可写等红色 + 原因 + 下一步建议重试 / 换目录
取消处理中取消蓝色，说明文件未改动重新开始
密码错误 / 需要密码加密 PDF红色 + 密码输入入口输入密码（仅本机）
格式不支持非 PDF / 损坏文件蓝色说明 + 支持列表换一个文件
功能未接入引擎不具备的能力明确说明，无云端兜底按钮查看可用工具

06无障碍与键盘

所有主要操作可键盘到达，焦点环统一 2px #1F6FD0 + 2px 偏移；触控目标 ≥ 32px（主导航与主按钮 ≥ 36px）；支持 prefers-reduced-motion。

快捷键动作说明
Ctrl + O打开 PDF与首页主按钮一致
Ctrl + Z / Ctrl + Shift + Z撤销 / 重做页面排序、旋转、复制、删除
Ctrl + S另存副本先确认，再演示
← → / PageUp PageDown上一页 / 下一页输入框聚焦时不拦截
+ / -放大 / 缩小40%–250%，点击百分比回到适应宽度
Esc关闭对话框 / 浮层不丢失已填内容
Enter对话框确认文本域内不触发
图标按钮必须有文字替代。所有 .icon-btn 都带 aria-label 与 data-tip 悬浮说明；纯图形状态（如“仅本机”）同时提供文字，灰度打印下仍可读。
